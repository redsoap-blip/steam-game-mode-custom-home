# Hide Friends Playing

Standalone CSS Loader theme that hides the small friend avatars Steam shows on game tiles (including the `+N` counter) when friends are currently playing that game.

## Install

Copy the `Hide Friends Playing` folder into `~/homebrew/themes/` and enable it in CSS Loader; it has no options and applies as soon as the toggle is on.

## Known limitation

It only hides the avatar bar, not the friend activity feed elsewhere in the UI, and it relies on Steam class names that a client update can rename.
