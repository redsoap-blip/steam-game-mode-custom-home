# Titles Above Cards

Standalone CSS Loader theme that moves each game title above its tile in the "Recent Games" row and hides the now redundant "Recent Games" heading.

## Install

Copy the `Titles Above Cards` folder into `~/homebrew/themes/` and enable it in CSS Loader; there are no options, it applies as soon as the toggle is on.

## Known limitation

It only repositions titles in the home "Recent Games" section, not in the library grid, and the top ~14px of a label can be clipped at the grid edge; it also depends on Steam class names that a client update can rename.
