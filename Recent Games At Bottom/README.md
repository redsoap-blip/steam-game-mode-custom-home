# Recent Games At Bottom

Standalone CSS Loader theme that pins the "Recent Games" card row, together with the game name and playtime labels, to the bottom edge of the Steam home screen.

## Install

Copy the `Recent Games At Bottom` folder into `~/homebrew/themes/` and enable it in CSS Loader; there are no options, it applies as soon as the toggle is on.

## Known limitation

Because the row is fixed to the bottom while the artwork still spans the window, the crop and label placement can drift from the stock layout on unusual resolutions, and it uses Steam class names a client update can rename.
